## 已实现的主要功能
1. **主题切换**：右上角按钮可切换深色/浅色模式
2. **Tab 切换**：未来规划板块可切换查看不同方向
3. **回到顶部**：滚动超过 300px 后右下角出现回到顶部按钮
4. **导航高亮**：滚动页面时自动高亮当前所在板块的导航项
5. **进度条动画**：学习目标进度条进入视口时自动展开
6. **响应式布局**：适配手机端和桌面端
